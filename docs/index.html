C++ Architecture & Secure Coding Implementation

Core Components

  • CryptoUtils: Windows CNG (`BCryptGenRandom`) for 256-bit entropy token generation and constant-time memory comparisons.
  • InputValidator: Regex sanitization preventing SQLi, LDAPi, and XSS across credentials and tokens.
  • AuthenticationManager: Implements salted SHA-256 password hashing with lockout threshold (5 failed attempts).
  • SessionManager: Thread-safe session registry enforcing dual timeouts (Idle: 5m, Absolute: 30m) and session concurrency caps.
  • SecurityLogger: Thread-safe singleton logging security events while strictly masking bearer tokens.

Compiler & Safety Flags

  • /W4: Highest standard MSVC warning level
  • /sdl: Security Development Lifecycle compiler checks
  • /GS: Stack buffer overrun security cookies
  • /guard:cf: Control Flow Guard (CFG) exploit mitigation
  • Thread Safety: std::mutex and std::lock_guard across all managers
